# Categorical Data Analysis (STAT 4104)
## Assignment: Advanced Statistical Modeling

This repository contains the full solutions for the STAT 4104 assignment, covering Logistic, Poisson, ZIP, ZTP, and Negative Binomial regression models.

### Contents
- `main.tex`: The complete LaTeX source code for the report.
- `analysis.py`: Python implementations using `statsmodels`.
- `analysis.R`: R implementations using `MASS` and `VGAM`.
- `/data`: Folder containing all `.csv` and `.dta` files.

### How to Run
1. **Python:** Ensure you have `pandas` and `statsmodels` installed. Run `python analysis.py`.
2. **R:** Open `analysis.R` in RStudio. Ensure `library(VGAM)` is installed.
3. **LaTeX:** Compile `main.tex` using any LaTeX editor (like Overleaf).

### Key Findings
The analysis successfully identifies factors associated with hospital length of stay and student attendance behavior using Zero-Truncated and Negative Binomial models respectively.
